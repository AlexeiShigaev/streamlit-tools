# Streamlit Tools

Набор утилит для работы с Excel-файлами.

## Утилиты

| Утилита | Что делает                                           | Описание |
|---|------------------------------------------------------|---|
| 🔗 Сопоставление Excel | Поиск почты по ФИО с нормализацией пробелов и регистра. Полезно, когда есть список сотрудников и справочник почт, но они «не сходятся» из-за грязных данных | [pages/compare2xls.md](pages/compare2xls.md) |
| 📄 Excel → CSV | Приведение журналов смен к набору плоских CSV. Полезно, когда у файла много листов и в каждом есть мусорные столбцы. | [pages/tool-export-csv.md](pages/tool-export-csv.md) |

## Запуск

### Через Docker

    docker compose up --build -d

Открыть: http://localhost:8501

### Локально

    pip install -r requirements.txt
    streamlit run tools.py

## Добавить новую утилиту

1. Создать `pages/имя.py` по образцу существующих.
2. Создать `pages/имя.md` с описанием.
3. Зарегистрировать в `tools.py` через `st.Page(...)`.
4. Добавить строку в таблицу выше.

## Структура проекта

    tools.py              точка входа, навигация
    pages/                страницы утилит
      *.py                код утилиты
      *.md                README для каждой утилиты
    requirements.txt      зафиксированные версии
    Dockerfile            сборка образа
    docker-compose.yml    запуск одной командой
