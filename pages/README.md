# Список утилит

## tool-export-csv

**Что делает:** Конвертирует Excel-журнал в CSV.

**Как пользоваться:**
1. Загрузите Excel-файл
2. Выберите нужный лист (листы можно обрабатывать в любом порядке)
3. Отметьте лишние столбцы и удалите их — должно остаться 5
4. Фамилия, имя и отчество склеятся автоматически
5. Скачайте готовый CSV

**Как это работает:**
- В файле несколько листов, на каждом есть мусорные столбцы и строки
- Мусорные столбцы пользователь удаляет вручную
- Строки с пустой первой ячейкой удаляются автоматически
- Из пяти оставшихся столбцов ФИО склеивается в один, остаётся три
- При первом открытии показывается первый лист
- После обработки одного листа можно переключиться на другой — данные сбросятся
